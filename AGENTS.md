# Repository workflow guidance

- Treat this repository as an independent device-adaptation project. Continue on the existing adaptation branch and merge upstream updates there; do not create a new branch for each sync or open pull requests to the upstream repository.
- Treat build verification as a diagnostic stage, not a gate on compilation or artifact upload. A failed FIT, initramfs, USB image, or preflight check must emit a GitHub Actions `warning`, retain its log and summary, and continue with available raw build outputs.
- Keep compiler/build failures distinct from validation failures. A genuine compile failure may fail the workflow; a validator mismatch must not prevent uploading the compiled ITB and other available artifacts.
- When changing CKB01 board roles or device-tree expectations, keep the board DTS, `scripts/ckb01-fit.py`, and its test fixture in sync. Hardware-verified mapping: switch port 1 / PHY8 is physical LAN1 and is WAN; switch port 2 / PHY9 is physical LAN2 and is LAN. PHY reset uses TLMM GPIO37, active low.
- If FIT validation fails, preserve the original compiled FIT as `artifacts/uimage-initramfs.itb` and use it as the fallback input for USB image packaging. Clearly mark it as unvalidated in the workflow warning and uploaded logs.
- CKB01 modem verification must inspect the actual compiled initramfs, using the package's installed paths: `qmicli` is `/usr/bin/qmicli`, `qmi-proxy` is `/usr/libexec/qmi-proxy`. Keep fixtures synchronized with the pinned packages. A guessed file path must never block ITB/IMG/log uploads.
- SDX55 control/data changes must retain the board + PCI/subsystem guard, avoid MHI runtime-reset loops, and distinguish a PDC response from its token/CID/message-matched indication. Leave an unmeasured endpoint unset rather than copy another modem's number.
- OEM management uses a private runtime under `/usr/lib/ckb01-oem/runtime`; do not replace global musl/OpenSSL libraries. The SDX55 payload is ARMv7 inside the AArch64 package: preserve its hash and do not run AArch64 strip on it. The timeout dependency installs `/usr/libexec/timeout-coreutils`. Keep advisory FIT content checks and existing fixtures aligned with these actual installed paths; DIAG node naming is independent of the module root management client.
- USB persistent-root /init must load `/etc/modules-boot.d/` before block discovery, use integer sleeps, and detach/exclude proc/sysfs and `/new_root` before RAM fallback copying. Select partition 2 by AIR5ROOT label, not USB enumeration order; keep FIT and rootfs from the same build. With `CONFIG_TARGET_PER_DEVICE_ROOTFS=n`, the compiled tarball can be `openwrt-qualcommax-ipq807x-rootfs.tar.gz`; missing rootfs must produce a warning and an explicitly labeled RAM-only artifact, never a false dual-partition success or blocked raw uploads.
- Preserve tarball UID/GID when populating ext4: run extraction and `mkfs.ext4 -d` in the same fakeroot session. Plain CI-user extraction writes uid/gid 1001 into ACL files; ubusd rejects them and wpad cannot publish hostapd/wpa_supplicant objects. Check actual ext4 ACL ownership using debugfs, and retain raw IMG/GZ even when this advisory check fails. Revalidate ART before ath11k every boot; a persistent calibration file does not recreate its RAM-only status. Keep the TCP19888 listener under an independent early procd service with an explicit SDX55 input rule; interface enumeration is not QMI/RPC connectivity proof.
- Keep the heartbeat destination `169.254.10.1/32` in netifd's loopback address list alongside `127.0.0.1/8`. S14's temporary `ip addr add` is removed by network initialization; a listening socket alone does not prove its destination address survives boot. Distinguish the helper's no-reset policy from the kernel MHI driver's automatic health recovery, which can still request a reset.
- CKB01 uses the OEM 291 14-slot event layout with mainline core RX consumption. Preserve shared MSI5/6 and zero-element offload slots 8/12/13. Keep runtime M3/system suspend disabled and automatic PCI/core recovery blocked only for the exact board + PCI/subsystem profile; never substitute a reset loop for a failed query. First-fault snapshots use host contexts and PCI config, not BAR reads.
- Network channels prepare on ndo_open and unprepare on stop/remove. Keep IP_HW0 DOWN until independent management ping/RPC, QMI14 DMS and QRTR DMS checks pass within the 120-second bootstrap window. SIM rejection does not invalidate a working DMS transport. The measured local endpoint is PCIe type3/interface4 (`packages/ckb01-modem/files/endpoint-evidence.json`); accept only WDA-confirmed raw-IP/no aggregation for this version. Do not restore QMAP trials, automatic MBN selection or unlock attempts.
- FIT modem validation compares the installed bootstrap, protocol and endpoint evidence against their source files. Keep test archive contents synchronized with actual installed files. Failures remain advisory and must retain raw ITB/IMG/log uploads; do not weaken or abort compilation to satisfy a fixture.
- MHI software consumption is an explicit diagnostic only: keep it off at boot, use the existing event lock/parser, retain the 30s/20ms/64-per-ring/4096-total bounds, and never publish modem-ready from it. Set fatal PM state under pm_lock before fault dumps so in-flight consumers cannot ring doorbells after detection. Keep collector exit cleanup paired with the timeout process groups, and do not treat a successful software drain as proof that SDX55 emitted no MSI.
- Kernel diagnostic patches must apply to the pinned OpenWrt patch stack, including generic 907/908/909 IRQ/DWC backports. Preserve `generic_handle_demux_domain_irq` and IRQ-work affinity redirection; its true return means dispatch accepted, not MHI handler completion. Keep a post-backport DWC fixture and compile the IRQ/DWC sources together.
- CKB01 PCIe0 must use the existing SoC GICv2m frame as `msi-parent`: same-kernel hardware A/B restored IPA completion interrupts, management ping/RPC and QMI14 with software polling off. Keep this route local to CKB01, let Linux allocate MSI data/SPI values, and synchronize the compiled-DTB check and fixture. Do not claim an exact TLP attribute fault without packet evidence; preserve advisory validation/upload behavior.
